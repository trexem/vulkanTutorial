# vulkanTutorial
This is a repo where I'm following the [Khronos Vulkan Tutorial](https://docs.vulkan.org/tutorial/latest/00_Introduction.html) with Vulkan 1.4, C++23 with modules and trying to follow best practices.

You need `gcc 16` and `vulkanSdk` for this project to build. And you can just run 
```shell
./build.sh
```
to build the project and run
```shell
./runGame.sh
```
to run the engine/game.
